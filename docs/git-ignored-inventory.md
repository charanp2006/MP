## Why Ignored Items Are Not on GitHub

- GitHub only contains committed objects; ignored files are not committed.
- Raw Azure data is intentionally local-only for this repository. A fresh clone will not include it; use `docs/azure-dataset-availability.md` to regenerate or re-download it.
- Caches and bytecode are intentionally local-only because they are machine/runtime-specific.
- M8 run logs are intentionally local-only because they are regenerable raw execution output.

## Recommended Handling

1. **Leave ignored paths ignored.** Do not use `git add -f` on raw data, model files, caches, secrets, or run logs.
2. **Do not treat malformed `C\357\200\272CharanMPscripts/` files as source of truth.** Use tracked `scripts/`, `forecasting/`, and `rl/` files.
3. **Delete caches only if needed.** `__pycache__/` and `.pytest_cache/` are safely regenerable.
4. **Keep secrets out.** If an `.env`, kubeconfig, OpenRouter key or HF token is ever created locally, it must stay ignored and never be printed, committed, or copied into docs/logs/results.
