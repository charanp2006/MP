## Objective

Turn the M9 adapter into an integration-ready ingestion SDK/API that can accept
records from external applications and the synthetic client, validate a stable
schema, enforce authentication without persisting tokens, preserve supplied
resource metrics and produce fixed-window traces with explicit metric provenance.

## Scope

- Add a shared schema module and generated JSON schema artifact.
- Support an envelope/API-style request with a bearer token separate from records.
- Preserve optional resource metrics (CPU, memory, latency, power, containers,
  cold starts) instead of always deriving proxies.
- Add `source`/`metrics_source` provenance and allowed-source validation.
- Add a CLI for JSONL ingestion plus focused tests.

## Design / data contracts

- Required event fields: `timestamp`, `service_id`, `function_id`, `invocation_count`.
- Optional fields: `request_id`, `payload_class`, `execution_duration_ms`,
  `error_count`, `source`, `scenario`, resource metrics.
- Auth: token supplied in an envelope/header field, compared with
  `hmac.compare_digest`, never written to events, traces or manifests.
- Aggregation: counts sum, durations/latencies/resource values average, cold
  starts sum, container counts use maximum within each fixed window.
- Trace column `metrics_source` is `observed`, `derived` or `mixed`.

## How to run and verify (planned)

```bash
python -m data.generic_adapter --input events.jsonl --out trace.csv --schema ingestion_schema.json
python -m pytest tests/test_generic_ingestion.py -q
python -m pytest -q
```

## Acceptance criteria

- C2-01: schema validation with clear errors for malformed/untrusted records.
- C2-02: bearer-token auth via envelope, constant-time comparison, no token persistence.
- C2-03: observed resource metrics preserved; missing fields derive labeled proxies.
- C2-04: generic adapter accepts both synthetic and external-style sources.
- C2-05: full test suite remains green.

## Limitations / next steps

- No network server is included; the API boundary is an in-process SDK/envelope.
- Resource metrics remain untrusted until validated and source-labeled.
- Live instrumentation adapters are outside this component.
