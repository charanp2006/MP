## 1. Objective

Close the loop: collect runtime metrics, feed them back to planning/control, run baseline-vs-proposed experiments with ablations, and produce auditable reports.

## 2. What was built

| Module | Responsibility |
|---|---|
| `monitoring/metrics.py` | In-memory counters/gauges/histograms, `MetricsCollector`, Prometheus text export |
| `monitoring/feedback.py` | `FeedbackLoop` computing caution/violation-rate/P95 trend from recent steps |
| `monitoring/__init__.py` | Public API |
| `experiments/run_experiments.py` | `run_baseline_vs_proposed`, `ablation_remove_planner` |
| `orchestrator/decision_loop.py` | Optional metrics recording + feedback signal in `Decision` |
| `configs/project.yaml` | Added `monitoring:` section |
| `tests/test_monitoring.py` | Monitoring/feedback/experiment tests |

## 3. How to run

```bash
py -m experiments.run_experiments
py -m pytest tests/test_monitoring.py -v
py -m pytest -q
```

## 4. Limitations & next steps

- Real Prometheus scrape/Grafana dashboards not deployed (scaffold only)
- Feedback is a soft signal; no automatic checkpoint retraining
- Experiments use the simulator; real cluster runs need P4 deployed
