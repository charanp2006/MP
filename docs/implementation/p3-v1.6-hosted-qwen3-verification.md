## 3. Secret Handling

- Tokens are read only from environment variables.
- No token keys are stored in `configs/project.yaml`.
- `.env`, `.env.*`, `*.secret` and local configs are gitignored.
- Bearer headers are built in memory only.
- `redact_text()` now handles labelled secrets, `Bearer <secret>`, `hf_*` tokens and `sk-or-v1-*` tokens.
- Do not paste tokens into chat, docs, configs, logs, screenshots or result files.
- Verify without printing secrets:

```powershell
if ($env:HF_TOKEN) { "HF_TOKEN is set" } else { throw "HF_TOKEN is not set" }
```

Do not run `echo $env:HF_TOKEN` or commit shell history containing secrets.

## 4. Owner Authorization Required

Approval must be explicit before any paid endpoint is provisioned or called. The required owner decision is:

1. Approve paid Hugging Face Inference Endpoint use and continued cost during the smoke.
2. Approve the exact model, revision, region and hardware.
3. Approve running one smoke through the project's HF provider path with an env-only token.
4. Approve stopping or scaling down the endpoint after evidence is captured.
5. Decide whether OpenRouter backup verification is in scope.

No paid endpoint was provisioned in this pass. No hosted inference request was made.

## 6. Real Hosted Run Procedure

Only after owner approval and endpoint readiness. Use `example.env` as the placeholder-only template; copy it locally to `.env` if needed (`.env` is gitignored) or load the values into the shell. Never commit a filled env file.

```powershell
$env:HF_ENDPOINT_URL = "https://<endpoint-id>.<region>.endpoints.huggingface.cloud/v1/chat/completions"
$env:HF_MODEL_ID = "<dedicated-endpoint-name-or-model-repo-id>"
$env:HF_TOKEN = "<hf_token>"
Remove-Item Env:HF_MODEL_REVISION -ErrorAction SilentlyContinue
Remove-Item Env:OPENROUTER_API_KEY -ErrorAction SilentlyContinue

python -m scripts.evaluate_planner --runtime huggingface --out-dir results/planner/huggingface
```

Get values from:

- endpoint URL and endpoint name: HF Inference Endpoints → endpoint → Inference API,
- token: HF Settings → Access Tokens, with the minimum required read access,
- revision: model repository branch/commit only when using model-router mode; leave unset for a dedicated endpoint.

`--model` does not override `HF_MODEL_ID` when the env var is set. Keep env and CLI model references consistent.

Expected success evidence:

```text
provider_counts: {"huggingface": 6}
status_counts: {"ok": 6}
valid_rate: 1.0
fallback_rate: 0.0
```

Expected artifacts:

- `results/planner/huggingface/planner_evaluation.json`
- `results/planner/huggingface/planner_evaluation.csv`

These artifacts were not created in this preparation-only pass.

## 7. Evidence Contract for a Future Real Run

Record only non-secret metadata:

- provider: `huggingface`,
- model ID and endpoint name,
- model revision if applicable,
- date and branch,
- exact command,
- scenario count,
- provider/status counts,
- validity and fallback rates,
- mean and p95 planning latency,
- strategy counts,
- downstream guard/action codes,

Do not record endpoint URLs with embedded credentials, bearer headers, tokens, or raw secret-bearing errors.
